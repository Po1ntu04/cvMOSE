\begin{abstract}
MOSEv2 将视频目标分割（Video Object Segmentation, VOS）的困难从“短时外观传播”推进到“复杂真实场景中的物理实例持续确认”：目标可能在首帧即被遮挡或位于边缘，随后长期消失、尺度剧变并以不同视角重现；画面中还可能同时存在多个高度相似的同类对象。本文面向 MOSEv2 作业的严格约束——仅给定首帧真值掩码、不训练或微调、不得使用后续真值——构建了一套以 SAM~2 为稳定传播基座的训练自由重锚定系统 \method{}。系统不把高置信掩码等同于正确身份，而是将推理划分为稳定传播、不确定性审计、候选再获取、身份验证、延迟提交与有界回传六个阶段。其核心包括：（1）面向消失/重现事件的对象中心时序账本；（2）由首帧、消失前可靠帧和同类干扰物共同构成的正/负身份记忆；（3）DINO/SAM 编码特征、几何运动约束和多模态大模型（MLLM）事件链推理的分工式验证；（4）经连续帧确认后才调用 \code{add\_new\_mask/box} 的伪锚点注入；（5）只在局部窗口改写输出、并以稳定基线为回滚点的逐对象保守融合。

在 433 个验证视频的官方提交协议下，418 个已提供视频始终保持逐路径不变，仅对剩余 15 个视频推理。平台反馈表明，原始 SAM2.1-Hiera-B+ 的 \jf{} 约为 43.24；单纯后处理、记忆门控和广泛候选融合大多只能达到 43.26--43.30。本文方法通过三个可解释的对象级修复将分数逐步提升至 43.54：低对比小目标的官方大模型区间替换使 \code{z6dx46qr} 提升约 24.67 个对象分；同类袋鼠重现重锚定使 \code{amfdu83t} 提升约 56.40；基于“向镜头运动—下边缘重现—后期消失”事件链的 \code{q0sizv6m:obj2} 修复使该对象由 12.34 提升至 68.29。实验同时揭示，MLLM 的语义解释并不能代替像素候选生成，视觉上合理的单帧候选也可能对应错误实例；激进融合反而从 43.44 降至 43.38。本文因此主张：复杂 VOS 的关键不在于继续调整单帧阈值，而在于建立“传播之外的新证据通路”，并让新证据经过物理一致性验证后谨慎改变模型的记忆轨迹。

{\Large\bfseries Training-Free Re-anchoring for Complex Video Object Segmentation}
\end{center}
\vspace{0.5em}
\noindent\textbf{Abstract.}
MOSEv2 stresses persistent physical-instance identity under occlusion, reappearance, tiny objects, severe appearance changes, and dense same-class distractors. Under a first-frame-mask-only and no-finetuning protocol, we develop \method{}, a training-free system that retains SAM~2 as the stable propagation path but augments it with an object-centric temporal ledger, distractor-aware positive/negative memory, high-recall candidate retrieval, delayed pseudo-anchor promotion, bounded re-propagation, and conservative per-object fusion. An MLLM is used only for event interpretation and candidate veto/support; it never generates masks or independently promotes anchors. On the 433-video submission protocol, while preserving all 418 provided outputs, the system improves the measured \jf{} from approximately 43.24 to 43.54. Detailed hidden-feedback analysis attributes the gain to three physically interpretable object-level corrections rather than broad threshold tuning. The results show that reliable progress in complex VOS requires a new evidence path for re-identification and re-acquisition, not merely safer suppression of uncertain predictions.

\vspace{0.5em}
\noindent\textbf{Keywords:} video object segmentation; MOSEv2; SAM 2; re-anchoring; distractor-aware memory; multimodal large language model

\section{引言}

\subsection{研究背景}
半监督视频目标分割要求模型在首帧给定目标掩码后，预测该物理实例在后续所有帧中的像素区域。早期数据集中的目标通常较大、显著且遮挡有限，因此“把首帧外观沿时间传播”已能获得较高性能。MOSE 与 MOSEv2 刻意打破这些温和条件：它们包含拥挤场景、长遮挡、消失与重现、多镜头、阴影反射、极小目标和外部知识需求，迫使模型真正解决“谁还是谁”的问题\cite{ding2025mosev2}。

SAM~2 将图像分割基础模型扩展为流式视频分割器：当前帧特征通过 memory attention 读取历史掩码记忆与对象指针，掩码解码器输出目标掩码，再把结果编码回记忆以服务未来帧\cite{ravi2024sam2}。这一设计兼具交互性和效率，但也引入了自回归风险：一旦某帧误跟到同类干扰物，错误掩码会成为后续的“历史证据”，从而形成稳定但错误的轨迹。SAM2Long\cite{ding2024sam2long} 和 DAM4SAM\cite{videnovic2024dam4sam} 分别从多路径记忆树与干扰感知记忆角度说明，复杂视频中的主要瓶颈确实位于记忆治理和身份恢复，而非单帧边界质量。

本作业进一步形成了一个特殊而有研究价值的约束：验证集共 433 个视频，其中 418 个结果已提供，仅需对剩余 15 个视频使用首帧掩码推理；最终提交仍必须包含全部 433 个目录。于是，任何提升都必须同时满足两点：一方面，对极少量困难视频进行高价值修复；另一方面，绝不能破坏 418 个已提供输出和原本稳定的预测。该设置把研究问题从“平均意义上训练一个更强模型”转化为“在不训练条件下，如何审计、恢复并安全提交少量高风险实例”。

\subsection{问题定义}
给定视频帧序列
\begin{equation}
  \mathcal{V}=\{I_t\}_{t=0}^{T-1},\qquad I_t\in\mathbb{R}^{H\times W\times 3},
\end{equation}
以及首帧中 $K$ 个实例的标签图 $Y_0\in\{0,1,\ldots,K\}^{H\times W}$，目标是在不访问 $Y_{t>0}$ 的条件下预测
\begin{equation}
  \hat{Y}_{1:T-1}=f(\mathcal{V},Y_0;\theta),
\end{equation}
其中参数 $\theta$ 在本作业中固定，不允许训练或微调。对任一实例 $k$，预测不仅要满足区域重叠和边界精度，还要保持物理身份一致：若 $o_t^k$ 表示时刻 $t$ 的真实物理对象，则输出非空掩码的前提应为“当前候选确为 $o_0^k$ 的延续”，而不是“当前画面存在同类别对象”。

官方指标 \jf{} 综合区域相似度 $\mathcal{J}$ 与轮廓准确度 $\mathcal{F}'$。本文沿用平台评测器，不重新定义其数据集级聚合；对单帧区域，$\mathcal{J}$ 为交并比
\begin{equation}
\mathcal{J}(M,\hat M)=\frac{|M\cap\hat M|}{|M\cup\hat M|},
\end{equation}
$\mathcal{F}'$ 衡量预测与真值边界的匹配质量。由于隐藏真值不可见，本文将平台对象级明细、模型间差异和逐帧语义审计联合用作实验反馈。

\subsection{核心观察与贡献}
本文的核心观察是：\textbf{掩码质量、类别相似与实例身份是三个不同层次的命题。} 一个面积稳定、边界清晰且与首帧同类的候选，仍可能是错误实例。由此产生三项贡献：

\begin{enumerate}[leftmargin=2em]
  \item \textbf{系统性失败归因。} 基于 15 个待推理视频的逐帧审查，将主要错误统一为“可见性不确定、同类身份歧义、极小目标证据不足、运动/视角变化和复合掩码污染”，并证明纯输出压制与局部阈值门控只能降低风险，不能完成身份恢复。
  \item \textbf{训练自由重锚定闭环。} 构建由状态审计、候选池、正负身份记忆、MLLM 事件账本、延迟提交、有界传播和保守融合组成的闭环。该闭环在结构上区分“提出假设”“验证身份”和“写入长期记忆”，避免单帧候选直接污染主轨迹。
  \item \textbf{隐藏反馈驱动的可解释验证。} 所有提交保持 418 个 provided outputs 不变，并用对象级得分定位真实增益来源。最终 43.54 的提升可被三个具体物理事件解释，而非来自不可审计的全局阈值扫描。
\end{enumerate}

\section{相关工作}

\subsection{SAM 2 与流式视频记忆}
SAM~2 由图像编码器、memory attention、prompt encoder、mask decoder 和 memory encoder 组成\cite{ravi2024sam2}。每帧图像先被编码为多尺度视觉特征；memory attention 将当前特征与过去的空间记忆和对象指针融合；解码器在提示条件下输出掩码与质量估计；memory encoder 再将预测编码回记忆库。其优势是原生支持点、框、掩码等交互提示，并能在新提示后继续传播；因此，经过验证的后续帧掩码可以作为重锚点改变整个后续推理轨迹。

然而，原生传播采用近似贪心的历史选择。SAM2Long 将每帧的不确定性用于构建多个记忆路径，并通过树搜索保留替代假设，在无需训练的情况下提升长视频稳定性\cite{ding2024sam2long}。这一工作启发本文保留 provisional branch，但其多路径仍主要来自模型自身预测，未必能在所有路径均丢失正确实例后重新生成目标候选。

\subsection{干扰感知记忆与再检测}
DAM4SAM 把跟踪中的干扰物显式写入记忆，使模型学习区分目标与相似负例，并以 introspection 管理何时更新记忆\cite{videnovic2024dam4sam}。其思想对 MOSEv2 极为关键：同类对象不是噪声，而应作为长期困难负例。然而，直接套用外部 tracker 在本任务的 smoke 实验中仍会产生大面积同类复合掩码，说明“有负例记忆”并不自动等于“候选分离正确”。本文因此将负例库与对象级候选枚举、延迟提交结合，而非把外部 tracker 的非空输出直接视为改进。

\subsection{SAM 3、语义提示与对象检索}
SAM~3 把检测、分割与跟踪统一到更强的提示接口中，增强文本/概念提示能力\cite{carion2025sam3}。但本任务输入是首帧实例掩码，而非开放词汇类别；“找到一只仓鼠”不足以区分“找到首帧指定的那一只仓鼠”。我们的 SAM3 适配实验表明，语义候选能力可用于提高召回率，却不能替代实例身份验证。

2026 PVUW MOSE 竞赛报告进一步印证了这一点。TEP 按 regular、tiny 和 semantic-dominated 目标分路由，并以外部跟踪/MLLM 提示补充基础模型\cite{zhang2026tep}；Re-Prompting SAM~3 则在后续帧用检测器生成同类候选，通过 DINOv3 对象级检索与变换感知特征池选择新锚点，再注入视频跟踪器\cite{gao2026reprompt}. 本文吸收其“later-frame object retrieval”范式，但为作业约束增加三项安全机制：困难负例 margin、连续帧确认与局部窗口回滚。

\subsection{多模态大模型的角色边界}
MLLM 能描述“拿起—遮挡—移动—放下”或“向镜头靠近—从下边缘重现”等事件链，但直接输入大尺寸多帧 panel 容易超时，且模型输出的坐标与掩码精度不稳定。本文采用 split harness：先对少量关键帧做短视觉 caption，再由深度思考模型在纯文本层聚合事件链。MLLM 仅负责目标画像、候选支持/否决和状态路由，不能直接输出最终掩码，也不能单独提升锚点。这一边界避免将语言合理性误当作像素正确性。

\subsection{提交协议与不可破坏不变量}
实验遵守以下硬约束：
\begin{itemize}[leftmargin=2em]
  \item 不训练、不微调、不使用后续真值；公开预训练权重仅作为推理候选源，并在报告中标记其提交资格；
  \item 418 个 provided outputs 必须路径一致且内容不变；
  \item 15 个待推理视频的第 0 帧必须逐像素保留给定标签；
  \item 最终压缩包包含 433 个视频目录与 66,526 张 PNG，标签值、帧数和命名均由验证器检查；
  \item 新方法写入独立预测根目录，任何失败均可回滚到 SAM2/M11 稳定基线。
\end{itemize}

\subsection{为什么可靠性阈值不足}
早期 M2 采用面积、中心位移、阈值扰动稳定性和内部 IoU/objectness 作为 memory gate。这类特征能发现“明显坏掩码”，却无法发现“稳定地跟错了另一只同类动物”。令 $q_t$ 表示掩码质量，$i_t$ 表示身份正确性，则实践中存在
\begin{equation}
  q_t\approx 1 \quad\text{但}\quad i_t=0.
\end{equation}
如果仍用 $q_t$ 更新 previous state，错误候选会迅速成为新的几何参考；后续所有运动检查都围绕错误轨迹展开。M11 的输出级 cycle gate 更安全，但只能把可疑片段清空，不能生成正确目标。由此可见，系统必须提供传播之外的独立候选源和身份证据。

\subsection{稳定传播与三态状态机}
对每个视频对象独立维护状态 $s_t\in\{\texttt{stable},\texttt{ambiguous},\texttt{recovery}\}$。状态输入不是单一置信度，而是一个结构化 \code{FrameAudit}：
\begin{equation}
  a_t=(e_t,o_t,p_t,\Delta A_t,\Delta x_t,u_t,d_t),
\end{equation}
其中 $e_t$ 为连续空帧数，$o_t/p_t$ 为 objectness 与预测 IoU，$\Delta A_t$ 为面积变化，$\Delta x_t$ 为中心运动残差，$u_t$ 为候选分歧，$d_t$ 为身份 margin。稳定状态下完全沿用原始 SAM2，避免高风险控制器破坏本来正确的视频；出现空帧、置信下降、来源分歧或运动不可达时进入 ambiguous；确认目标消失或主路径失效后进入 recovery。

与二值 accept/reject 不同，ambiguous 状态允许候选继续输出到 provisional branch，但禁止写入长期身份记忆；recovery 才触发全局/局部候选再获取。只有重新确认后才回到 stable。

\subsection{锚点库与干扰感知身份记忆}
每个对象维护
\begin{equation}
  \mathcal{B}_k=\{A_k^{0},\mathcal{P}_k,\mathcal{R}_k,\mathcal{N}_k\},
\end{equation}
分别表示首帧锚点、消失前高质量正例 reservoir、已验证重现锚点和困难负例库。正例不是“最近帧”，而是身份仍清晰、形态具有代表性的帧；负例来自同帧其他对象、M11 cycle 拒绝片段、非选中自动掩码、附近同类候选、context ring 以及已知错误来源。

候选 $c$ 的基础身份分数不是只计算与正例的相似度，而是正负差值
\begin{equation}
  m(c)=\max_{p\in\mathcal{P}_k\cup\mathcal{R}_k}\cos(f_c,f_p)
       -\max_{n\in\mathcal{N}_k}\cos(f_c,f_n).
  \label{eq:margin}
\end{equation}
描述器 $f$ 可由 DINOv2/DINOv3 patch token\cite{oquab2023dinov2}、SAM2 Hiera 图像特征与颜色/形状统计融合。对普通目标，使用掩码内 token 均值与上下文环差分；对极小目标，若掩码覆盖 token 少于 3 个，则改用扩大局部框的 crop descriptor，避免全图平均淹没目标。

\subsection{高召回候选池}
恢复首先追求“正确目标出现在候选池中”，而非立即保证所有候选可靠。候选源包括：
\begin{enumerate}[leftmargin=2em]
  \item SAM2 当前主路径和 M11 保留/拒绝 tracklet；
  \item SAM2Long、官方 large/long、DAM4SAM/d4sm、SAM3/SAAS 等独立 tracker 输出；
  \item SAM2 automatic mask、point-grid proposal 与高分辨率 tiny crop；
  \item 后续高置信帧的反向传播候选；
  \item 光流或全局相机运动引导的搜索区域；
  \item MLLM 事件账本提出的空间约束（例如“下边缘重现”），但不直接采用其坐标为掩码。
\end{enumerate}

这种设计把 proposal recall 与 identity precision 解耦。外部模型可以提出候选，但不会直接进入最终提交；即使多个来源一致，也需判断它们是否共享同一错误，例如都跟到更显眼的同类对象。

\subsection{对象中心时序账本与 MLLM split harness}
仅比较首帧与当前帧 crop，无法处理物体转体、遮挡或被拿取。本文为每个对象建立事件账本
\begin{equation}
  \mathcal{L}_k=\{(t,v_t,r_t,\pi_t,\mathcal{D}_t)\},
\end{equation}
其中 $v_t$ 为可见状态（visible/partial/absent），$r_t$ 为相机与目标相对运动，$\pi_t$ 为可达位置/尺度，$\mathcal{D}_t$ 为同类干扰物状态。账本回答的不只是“当前像不像”，还包括“若这是同一物体，它从上一状态如何物理地到达这里”。

受 Qwen-VL 系列视觉理解接口\cite{bai2025qwen25vl} 启发，为避免 qwen3.6-plus 直接处理大尺寸多帧 panel 的超时和注意力稀释，我们将推理拆成两级：
\begin{enumerate}[leftmargin=2em]
  \item \textbf{帧级视觉描述：} 每次只输入一个小型 crop/context panel，短输出目标可见性、相对位置、动作和候选编号；超时后自动缩小为 crop-only 重试。
  \item \textbf{文本级事件聚合：} 将多个帧 caption 与候选表交给深度思考模型，推断“离场重现”“拿起移动放下”“向前景运动”等事件链，并输出支持、否决或不确定判断。
\end{enumerate}
模型不接触后续 GT。若 MLLM 不确定，same-class dense 对象默认拒绝锚点，tiny 对象保持基线，稳定对象不启用恢复。此策略把语言模型定位为“物理故事审计器”，而非分割器。

\subsection{延迟提交与伪锚点注入}
单帧候选首先进入 provisional 状态。候选只有满足下列条件才可晋升：
\begin{equation}
\mathrm{promote}(c_t)=
\mathbf{1}\left[m(c_t)>\tau_m\right]
\land \mathrm{TemporalConfirm}(c_{t:t+2})
\land \neg\mathrm{Veto}_{\mathrm{MLLM}}
\land \mathrm{Reachable}_{\mathcal{L}}.
\end{equation}
TemporalConfirm 默认要求连续两帧或未来三帧中的两帧具有相同来源/重叠和正 margin；若视频已接近末尾，则需要更强的 identity margin 或反向 cycle。对同类密集目标，MLLM 的高置信支持最多是附加证据，不能单独满足 promote。

验证通过后，通过 SAM2 原生接口
\begin{equation}
  \mathrm{add\_new\_mask}(t,k,M_t^*)
  \quad\text{或}\quad
  \mathrm{add\_new\_box}(t,k,B_t^*)
\end{equation}
重新驱动跟踪器，而不只是把候选 PNG 粘到输出。这样新锚点会改变 memory attention 所读到的 conditioned memory，并在前后局部窗口重新传播。

\subsection{有界重传播与保守融合}
重传播仅作用于锚点附近的时间窗口 $[t-r_b,t+r_f]$，窗口外保持稳定基线。若新轨迹与 SAM2/M11 的差异超过阈值，且身份置信不足，则整段回滚。最终融合粒度为 video/object/segment，而非像素投票：
\begin{equation}
\hat M_t^k=
\begin{cases}
M_{t,\mathrm{reanchor}}^k,& t\in\Omega_k\ \text{且通过审计},\\
M_{t,\mathrm{M11}}^k,& \text{风险场景},\\
M_{t,\mathrm{SAM2}}^k,& \text{稳定场景}.
\end{cases}
\end{equation}
这使“外部候选失败”不会扩散成全视频回归，也使 418 个 provided outputs 天然保持不变。

\subsection{实验协议}
所有候选首先在关键视频 smoke test，只有至少两个对象出现明确改善且稳定 guard 视频无严重回归时才扩展到 15 个视频。视觉比较统一包含 RGB、SAM2、M11、候选输出、差异图和局部放大。隐藏评测反馈到达后，使用对象级行分析增益归因，而不把总分四舍五入后的相同值误判为等价方法。

最终提交由验证器检查：视频目录数、PNG 总数、逐视频帧数、标签合法性、首帧保留、418 个 provided outputs 哈希/路径不变。由于后续真值隐藏，本文把“平台对象行提升 + 多帧物理一致性 + 无 stable regression”作为接纳新策略的联合标准。

\subsection{候选模型与计算设置}
基础模型为 SAM2.1 Hiera-B+；官方 large/long、SAM2Long、DAM4SAM/d4sm、SAAS、SAM3 仅作为候选或上界诊断。DINOv2 ViT-B/L 用于对象级 embedding。MLLM 调用通过阿里云百炼 OpenAI-compatible 接口，视觉请求采用短超时与 mini retry，文本聚合使用 qwen3.6-plus 深度思考；所有请求按模型、prompt 和图像哈希缓存，防止重复成本和不可复现变化。

首帧目标麻将背面朝上，与待摸牌高度相似；第 1 帧被手遮挡，第 3--5 帧在运动模糊中可见七条特征，第 6--7 帧被放到面前牌列最左侧。早期 MLLM prompt 将“左侧牌”过度语言化，候选实际落在远处/上方牌列的二条，平台对象分仍约 2.13。该失败说明事件描述必须绑定可视证据和候选 ID，不能把用户叙述直接变成指向性坐标提示。

\paragraph{草莓切片（\code{r13u5z4y}）。}
首帧目标只露出被遮挡的一小段边缘，之后被手完全挡住并与另一切片同时移动。第 20 帧后目标重现于多个近似切片旁。M11 的空输出虽保守，却比错选原位置草莓更安全。当前候选源无法稳定枚举并分离每个切片，因而身份验证无从发挥。

\paragraph{旋转字母骰子（\code{4vznweiu}）。}
目标极小且自身旋转，表面字母随视角改变，邻近还有多枚相似骰子。高分辨率 crop 能改善可见性，却不能决定实例身份；先前 aggressive 窗口发生向相邻字母骰子的切换。正确方向是“同类对象全部编号 + 相对运动轨迹 + 多面外观记忆”，而不是继续扩大 crop。

\section{讨论}

\subsection{真正起作用的改动位于哪里}
从整条链路看，基础模型并非主要短板：SAM2 在目标连续可见时通常表现良好。有效改动集中在两个接口：
\begin{enumerate}[leftmargin=2em]
  \item \textbf{恢复证据接口：} 在主路径丢失后，生成一个物理上可解释、实例上可区分的后续锚点；
  \item \textbf{轨迹改写接口：} 把锚点通过 SAM2 原生提示重新注入，使 memory attention 读到新的 conditioned memory，并只在受控窗口提交。
\end{enumerate}
M11/M2/M3 等工作有意义，因为它们建立了安全阀、审计和候选表，但在没有高质量 later-frame anchor 时只能“少犯错”。M15/M17 首次显著提升，是因为它们完成了从事件理解到候选坐标、再到 SAM2 传播和提交融合的闭环。

\subsection{MLLM 的价值与限制}
MLLM 对本任务最有价值的能力不是类别识别，而是把离散帧组织为物理事件：目标是否被拿起、是否向镜头移动、是否真正离场、哪一个同类对象的运动与历史兼容。split harness 提高了调用稳定性，也减少大 panel 中的视觉遗漏。然而，语言模型仍存在三类限制：
\begin{itemize}[leftmargin=2em]
  \item 空间精度不足：正确故事不保证正确 bbox，更不保证像素边界；
  \item 提示偏置：具体视频叙述可能诱导模型寻找“被提示的对象”，形成高置信错选；
  \item 同类不可辨识：若帧中没有可观察的实例差异，任何语义模型都无法从单帧恢复身份，只能依赖运动和完整事件链。
\end{itemize}
因此，MLLM 应输出“候选之间的关系与风险”，并由传统视觉候选/描述器落实到像素。未来可让其维护结构化 scene graph，但仍需通过独立视觉 evidence gate。

\subsection{为什么仍未达到 44}
从 43.54 到 44 仍需约 0.46 个全局分，相当于 575 个对象行总计约 265 分。已修复的三个对象各贡献约 0.04--0.10，说明需要再完成数个类似量级的真实身份恢复。\code{8jsm23a7} 理论潜力最大，但候选身份仍错；\code{r13u5z4y}、\code{4vznweiu}、\code{1qlssuz2} 的可见像素少且同类密集。瓶颈不再是 pipeline 缺失，而是：
\begin{equation}
\text{正确实例是否进入候选池} \quad\text{以及}\quad
\text{能否在无 GT 下被可靠区分}.
\end{equation}
这要求更强的全视频对象提议与多对象轨迹维护，而不是继续扫描阈值。

\subsection{下一步研究方向}
\begin{enumerate}[leftmargin=2em]
  \item \textbf{多对象 candidate graph。} 对每个关键帧的全部同类候选建立节点，以光流、可达速度、遮挡关系和外观 margin 建边；目标恢复转化为带 absent state 的全局路径搜索。
  \item \textbf{DAM 与延迟 DRM promotion 深度融合。} 不只保存目标正例，还为每个同类干扰物维护独立记忆与运动状态；只有分支在未来帧持续与正例接近且远离负例，才晋升到主记忆。
  \item \textbf{SAM3 作为 proposal teacher。} 利用语义/概念 prompt 枚举同类候选，但继续由对象级 retrieval 和时序账本做实例选择；SAM2 仍可作为最终稳定传播器。
  \item \textbf{双向与多锚点一致性。} 从多个后续锚点前后传播，选择能同时解释首帧、消失前和重现后观测的路径，避免单锚点偶然匹配。
  \item \textbf{不确定性校准。} 用候选间相对 margin 和来源相关性替代绝对置信度；“多个模型一致”只有在其错误机制独立时才构成强证据。
\end{enumerate}

\section{结论}
本文针对 MOSEv2 中遮挡、重现、同类干扰和极小目标造成的实例身份丢失，构建了一套训练自由的对象中心重锚定系统。大量负结果表明，输出阈值、记忆写入门控、局部 crop 或单一外部 tracker 都不能单独解决身份恢复；它们最多降低错误传播。真正有效的路径是：在基础传播之外生成后续对象候选，以正负身份记忆和物理事件链验证，再通过原生 prompt 接口重写 SAM2 的局部记忆轨迹，最后以逐对象保守策略融合。

在保持 418 个 provided outputs 不变的前提下，系统将隐藏 \jf{} 从约 43.24 提升至 43.54。更重要的是，提升来源可以被明确归因到低对比小目标、同类袋鼠重现和前景小动物运动三个实例，而激进候选的回归也被隐藏评测证实。本文的主要结论不是“某个阈值最优”，而是：复杂视频分割需要从单路径自回归升级为“传播、审计、再获取、验证、延迟提交、回滚”的闭环；语义模型只有在与对象级候选和时序几何对齐后，才会转化为真实像素收益。
