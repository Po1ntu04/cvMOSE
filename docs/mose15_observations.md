# MOSEv2 15 个待测视频：关键问题观察与分析记录

> 目的：持续记录我们对 15 个待测视频、首帧 GT mask、SAM2/SAM3.1 输出差异的真实观察。后续任何数据集分析必须基于原帧/多帧语义内容和 mask 指定实例，不仅凭文件名、类别或单帧推断；不确定处必须明确标注。

## 0. 分析约束与方法要求

- **必须看原始帧语义**：分析视频时要查看多帧，尤其是首帧、遮挡前后、目标重现帧、边缘帧。
- **必须核对目标实例**：目标不是类别本身，而是首帧 mask 指定的具体实例；多同类物体场景中不能把相似物体当作目标。
- **必须区分证据与推断**：能从图片直接看到的写为“观察”；基于运动/遮挡连续性推测的写为“推断”；无法确定的写为“不确定”。
- **必须关注 mask 面积与位置**：小目标、边缘目标、被遮挡目标对传播链路影响很大。
- **必须保留失败模式**：即使某条方法形式上跑通，也要记录它是否真正追踪到目标。
- **必须显式核验不确定目标**：若首帧目标非常小、被遮挡、或后续重现时同类物体密集，后续结论只能写成“可能/推断”，不能把模型输出当作 GT。

## 2. 用户已明确指出的关键发现（整理版）

### 2.1 遮挡是核心难点

待测视频中存在明显遮挡。目标对象可能因为：

- 目标自身运动；
- 摄像头运动；
- 其他物体/手/同类目标的相对运动；
- 目标进入图像边缘或画外；

而短时或长时不可见。遮挡时长是否超过模型 memory bank 的有效上下文窗口，需要逐视频确认；但从目前观察看，多个视频已经不是单纯“连续局部传播”，而是需要“遮挡后重新辨认同一实例”。

### 2.2 多同类目标中的实例身份保持很难

很多视频不是“找这个类别”，而是“在多个相似目标中持续追踪首帧 mask 指定的那个实例”。当同类目标外观相似、互相遮挡、一起移动或靠近时，模型容易发生：

- **identity switch**：切到另一个同类实例；
- **drift**：目标重现后定位到更显眼、更近、或更完整的相似目标；
- **lost target**：遮挡后完全丢失。

### 2.3 首帧给定 mask 本身可能已经严重遮挡

有些视频首帧 GT mask 并不是完整目标，而只是被遮挡后的可见小区域。这意味着模型初始化 memory 时看到的目标外观、形状和真实完整物体差距很大。

典型例子：`r13u5z4y`（切草莓/手移动切块场景）。首帧 mask 指向靠后的草莓切块，但该切块已经被遮挡大部分，只露出边缘。随后目标被手完全遮挡，约 `00005` 附近不可见；约 `00020` 前后重新出现/被放下时，场景中已有多个相似草莓切片。实测中：

- SAM2 在目标重现后倾向定位到原有/更显眼的草莓切块，发生实例切换；
- SAM3.1 更容易完全丢失目标。

> 注：以上为用户基于人工观察提出的强观察点；本轮联系图复核也支持“遮挡后重现 + 多草莓切片同类干扰”是该视频的主要失败原因。

### 2.4 高速运动与多维运动比例高

目标常出现快速移动、转体、尺度变化、姿态变化、平移+旋转+遮挡叠加等复杂运动。前后帧的视角、空间位置关系不一定一致。

### 2.5 目标常在图像边缘

目标接近边缘或部分出画时，可见区域进一步减少，且容易和背景边界、其他物体发生混淆。`amfdu83t`、`c8lutf29`、`pe0d85lk`、`q0sizv6m`、`2smf7uq9` 都有明显边界/截断问题。

### 2.6 目标普遍很小

首帧共有 20 个目标实例，其中：

- 面积 `<=0.1%`：3/20；
- 面积 `<=0.5%`：6/20；
- 面积 `<=1%`：9/20；
- 面积 `<=2%`：13/20；
- 面积 `<=3%`：16/20；
- 面积 `<=5%`：18/20。

这会放大以下问题：

- mask resize/下采样后的细节损失；
- prompt/memory 中可用外观信息不足；
- 运动估计误差在小目标上占比很大；
- 遮挡后重识别困难；
- 与同类小物体的 identity switch。

## 5. 新增归纳问题要点

### 5.1 难点从“传播”升级为“遮挡后实例重识别”

很多失败并不是前后帧局部 mask 传播不稳，而是目标经过手、人体、边缘或同类群体遮挡后，需要重新判断“哪一个才是首帧那个实例”。这对只依赖首帧 prompt 或短期 memory 的方法非常不友好。

### 5.2 首帧 memory 可能是“残缺实例”而不是完整实例

`r13u5z4y`、`amfdu83t`、`2smf7uq9`、`pe0d85lk` 等视频中，首帧目标可能已经贴边、被遮挡或只展示局部。模型初始化时获得的是残缺外观，后续目标完整出现时反而可能不像首帧 memory。

### 5.3 同类干扰普遍存在，而且往往比目标更显眼

车辆、火烈鸟、狮子、考拉、豚鼠、草莓切片、字母方块、麻将/游戏牌都属于“同类或近似同类目标成群出现”。很多干扰物更大、更完整、更靠近画面中心，更容易被模型选中。

### 5.4 边缘/出画不是附加问题，而是核心问题

多个目标在首帧就靠近边界或被边界切断。边界目标没有完整轮廓，后续一旦出画/重入，普通 frame-to-frame tracking 很难判断它是否还是同一实例。

### 5.5 小目标会放大编码分辨率与后处理误差

面积低于 1% 的目标占 9/20。对于这类目标，模型编码器下采样、mask logits resize、阈值化、连通域选择的每个像素级误差都会在相对尺度上变大。

### 5.6 背景重复纹理会诱导漂移

道路标线、红黑座椅/Logo、白色字母方块、白色游戏牌、草莓切片、动物皮毛/草地、水下纹理都提供了重复局部模式。模型如果没有强实例约束，容易从“目标实例”退化为“局部相似区域”。

### 5.7 多目标视频还存在对象间合并/身份互换风险

`4f98052b`、`msinig6m`、`pe0d85lk`、`q0sizv6m` 不只是单目标困难，还需要同时维护多个 id。多个 id 之间如果靠近、遮挡或出画，模型可能合并、互换或只保留更显眼的一个。

### 5.8 SAM2 与 SAM3.1 的差异在这些数据上更像“任务契合度差异”

从现有输出看，SAM2 的视频传播/记忆链路更贴近该作业的输入形式：首帧 mask → 视频对象传播。SAM3.1 即使通过 adapter 跑通，也更容易表现为：

- 对小目标/残缺首帧 prompt 不稳定；
- 遮挡后保守地输出空；
- 或缺少面向 VOS 的实例记忆与传播约束。

这不等于 SAM3.1 “模型能力弱”，而是当前调用方式和任务结构不匹配：MOSEv2 作业需要的是首帧 mask 条件下的实例级视频传播与重识别，而不是只在单帧/短上下文中重新分割显著目标。

## 6. 后续分析执行原则

1. 每次分析具体视频时，先看首帧 GT mask 放大图，确认“哪个实例”被指定。
2. 至少查看首帧、遮挡前、遮挡中、遮挡后、末帧 5 类帧；若有 identity switch 风险，需要补充更多相邻帧。
3. 不能只看预测 mask 判断目标；必须回到原帧语义判断目标是否真实可见。
4. 对于极小目标，必要时生成局部 crop/zoom 后再判断。
5. 输出结论必须分成：观察、推断、不确定。
6. 若要对比 SAM2/SAM3.1，优先关注：空 mask 是否对应真实不可见、非空 mask 是否仍是首帧实例、重现后是否切到同类目标。

## 7. 当前总判断

该 15 视频集合更像是“困难小目标实例级视频对象分割”，而不是普通类别分割。它要求模型在小目标、遮挡、多同类实例、快速运动、边缘截断和长时重识别下保持首帧指定实例的 identity。SAM2 更适合该作业，并不意味着它能解决所有问题；它也会在长遮挡后、相似实例聚集后发生漂移。SAM3.1 通过简单 adapter 可以形式上生成输出，但在当前调用方式下，对这类首帧 GT mask 驱动的 VOS 任务契合度明显不足。
